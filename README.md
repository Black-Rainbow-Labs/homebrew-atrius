# Homebrew tap for Atrius

```sh
brew install black-rainbow-labs/atrius/atrius-index
```

Atrius is a code index for AI agents and for people: ripgrep's exact results from an index kept current
as files change, definitions, fragments and outlines in 24 languages, and an MCP server. The formula
installs the release archives from https://blackrainbowlabs.com/downloads/atrius-index/.

`Formula/atrius-index.rb` is written by the Atrius release, never by hand.
